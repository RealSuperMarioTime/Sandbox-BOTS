# Sandbox BOTS

Welcome to my first workshop addon! This project is still a work-in-progress, and I'll be rolling out frequent updates as I add new features and polish things up.

Inspired by StarFrost, I wanted to recreate these human-like players that are actual bots and not Nextbots. They behave almost like real players: they can walk, run, jump, crouch-jump, bhop when they retreat, spawn props, entities, and even NPCs. Spawn a few of them and watch them build, chat, and battle right alongside you!

## How to spawn them?
1. Go to **Options** -> **Keyboard** -> **Toggle developer console**
2. In the console, type: `SandboxBOTS_add`

## How to kick them all?
In the console, type: `SandboxBOTS_KickAll`

## Why are they not spawning?
⚠️ You need to be playing in **Multiplayer** (or start a local multiplayer peer-to-peer server) to spawn them.
